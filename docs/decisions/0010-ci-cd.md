# ADR 0010: GitHub Actions for CI/CD

- **Status:** Accepted
- **Date:** 2026-09-13

## Decision

Use GitHub Actions for continuous integration and continuous delivery workflows.

## Rationale

- Workflow definitions are version-controlled in the repository.
- Supports Ubuntu runners, PostgreSQL services, Docker, security scanning, artifact storage, and AWS deployment.
- Provides branch protection and pull-request quality gates.
- Supports environment approvals and deployment history.

## Alternatives rejected

- **Jenkins:** requires additional infrastructure and operational ownership.
- **GitLab CI:** strong capability, but the project baseline assumes GitHub repository workflows.
- **AWS CodePipeline as the sole CI system:** increases AWS coupling for checks that should remain repository-portable.

## Constraints

CI must enforce formatting, linting, type checks, tests, migrations, architecture checks, dependency scanning, and secret scanning before deployment.
